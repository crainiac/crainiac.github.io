REST DAYS
Wednesday, Saturday, Sunday.

EXERCISE ORDER
Follow the table from top to bottom, except:
Thursday: rows before bench press.
Friday: romanian deadlifts before split squats.

EFFORT
Finish each set with 2 clean reps remaining.
Warmup sets are additional.

REST BETWEEN SETS
3 minutes: bench, row, arnold press, split squat, romanian deadlift.
2 minutes: lateral raise, curl, calf raise, crunch.
For unilateral work, measure rest before repeating the same side.

PROGRESSION
Increase weight when every prescribed set finishes with more
than 2 reps remaining. Adjust load to preserve clean technique.
